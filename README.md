# Claude Code Patterns

A collection of reusable project patterns for working effectively with Claude Code.

## Patterns

| Pattern | Description |
|---------|-------------|
| [Meta Repo](patterns/meta-repo/README.md) | Use a wrapper repo as the workspace root to give Claude Code full context across multiple independent source repos. |

## Usage

Each pattern has a README explaining the problem it solves and how to apply it, plus a `template/` directory with starter files you can copy directly into your own project.

## Contributing

To add a new pattern:

1. Create a directory under `patterns/` named after your pattern (kebab-case)
2. Add a `README.md` following the structure in `PATTERN_TEMPLATE.md`
3. Include a `template/` directory with starter files
4. Add a row to the table above
